# План развития

## 1. Надёжность базовых компонентов

- Добавить тесты HTTP-клиента: тайм-аут, недоступный сервер, неверный JSON, неожиданный тип ответа, пустое содержимое.
- Унифицировать обработку ошибок обычного чата и запросов агентов.
- Проверить SQLite на временной базе: сохранение и восстановление сессий, добавление и удаление фактов.
- Проверить выход из начального меню по EOF и Ctrl+C, а также коды завершения демонстрации.

Критерий завершения: ожидаемые ошибки не завершают консоль необработанным исключением; проверки данных не используют рабочую базу.

## 2. Оценка качества Security Agent

- Зафиксировать небольшой набор корректных и ошибочных примеров с ожидаемыми замечаниями.
- Отдельно учитывать нарушения требований и реальные проблемы безопасности.
- Оценивать пропущенные ошибки, ложные замечания, обоснованность серьёзности и соблюдение формата.
- Изменять инструкции только с повторной проверкой всего набора.

Критерий завершения: воспроизводимый отчёт с результатами и ограничениями. Автоматическое исправление кода не включается на основании одного успешного примера.

## 3. Конфигурация и воспроизводимость

- Вынести модель, адрес и тайм-ауты в общую конфигурацию.
- Добавить автоматический запуск тестов в CI без модели и GPU.
- Проверять поддерживаемые версии Python и запуск из чистой копии.
- Определить поведение при превышении доступного контекста.

## 4. Планировщик

- Добавить структурированный план с допустимыми шагами и возможностями агентов.
- Проверять план до выполнения, ограничивать число шагов и сохранять последовательный запуск.
- Добавить журнал задач и понятное представление ошибок.

DevOps Agent и голосовой интерфейс — последующие направления после проверки базового планирования.
